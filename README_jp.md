# SphotographySP

SphotographySP — コンテンツを探索へと変える、全画面マップ型 WordPress 写真テーマ

# プロジェクトについて

> 基本理念：**管理画面でコンテンツを作り、フロントエンドで探索する。** 訪問者を迎えるのは記事一覧ではなく、画面いっぱいのベクターマップです。位置情報付きの写真がマーカーとなり、クリックすると記事が開き、該当ページや座標へ移動します。継続的に開発中です。PR や Issue を歓迎します。

SP 版は [Larker](https://github.com/LarkerO) が保守するフォークです。[元の Sphotography プロジェクト](https://github.com/ShirazuNagisa/sphotography/) に対し、新たなサポート、よりモダンなフロントエンド、AI らしさを抑えた表現を目指しています。

# 特徴

+ **全画面マップで探索** — MapLibre GL JS のベクターマップをホームに採用。CartoDB の Dark Matter / Positron を使用し、API トークンは不要です。写真はしずく形のマーカーとなり、近接点は gooey フィルターでリアルタイムに融合・分裂します。
+ **ナイトモード** — システム連動・ライト固定・ダーク固定の3段階。ダーク配色はクラシック・ブルー・パープルから選べます。
+ **サイドバーと記事** — 開閉可能なサイドバー、即時検索（`Ctrl / ⌘ + K`）、カテゴリー・地域フィルター、REST 経由の全文読み込み、Windows DWM 風のウィンドウ拡大アニメーション。
+ **フォトウォール** — 記事の写真を日付別に表示。固定表示、無限スクロール、絞り・シャッター速度・ISO を含む EXIF 詳細に対応。「撮影場所を見る」で地図上の位置へ移動します。
+ **地図との連動** — マーカーをクリックすると、地図に追従する写真グリッドを表示。デスクトップでは写真から記事をウィンドウアニメーションで開き、該当箇所へ移動します。記事内の位置情報付き画像をクリックすると、背景の地図が移動・拡大し、5 km/cm の縮尺でパネル右側に表示されます。ローカライズされた住所カードから Amap または百度地図で場所を確認できます。
+ **独自コメントシステム** — REST ベース。CAPTCHA、非公開コメント、メール通知、Markdown、絵文字、いいね、固定、編集履歴、UA、IP 地域、文字アバター、折りたたみ、ページ分割に対応。
+ **相互リンクとゲストブック** — WordPress のリンク管理を再利用し、mShots によるサムネイル自動生成、申請・承認に対応。ゲストブックはコメントエンジンを共用します。
+ **AI モジュール（実験的）** — API キーを持ち込み、AES-256 で暗号化保存してサーバー側のみで使用。文体・長さを調整できる記事補完・推敲、全文要約、自動タグ、単一／二重モデルによる画像理解と執筆に対応し、ネイティブブロック HTML を出力します。
+ **共有機能** — WeChat QR コード、QQ、Qzone、Weibo、X、Facebook、リンクコピー。テーマカラーの単色アイコンを使用します。
+ **多言語** — フロントエンドの 中 / A / あ 切り替え。静的辞書、必要時のモデル翻訳、サーバーキャッシュを組み合わせ、記事翻訳は保存時に事前生成します。
+ **統計** — 展開サイドバーの詳細統計、地域別円グラフ、段違いの記事一覧、カード内の文字数・閲覧数。
+ **地域の色分け** — `region_tag` 地域タグ、行政境界の必要時ダウンロード・配信、地域フィルターと区画集計、地図のテーマカラーフィルター。
+ **細部の工夫** — iPad 風の角丸吸着カーソル、自動で閉じられるフローティング告知、記事内目次、読書進捗、ページリンクバー、記事カバーのぼかし背景など。
+ **全設定のエクスポート／インポート** — 全設定を JSON で一括入出力。暗号化 API キーの平文での書き出し・復元、相互リンク、ゲストブック設定、地域色を含みます。
+ **管理機能** — 独立した最上位設定ページ、EXIF 一括抽出（GPS・カメラ・日付）、CDN 切り替え（jsDelivr / unpkg / cdnjs）、GitHub ブランチからの更新、任意の Sphotography 管理画面スタイル。
+ **技術的特徴** — フレームワーク・グローバル汚染のない素の JavaScript。REST と PHP インラインデータの二経路で、403 時は自動切り替え。CSS 変数ベースのデザイン、3段階のレスポンシブ対応、アクセシビリティと動きを減らす設定への配慮。

# インストール

[Releases](https://github.com/LarkerO/sphotography/releases) から ZIP をダウンロードし、WordPress の「外観 → テーマ」でアップロード、インストール、有効化してください。

有効化すると、`region_tag` タクソノミーを登録し、「全画面マップ」ページテンプレートを作成して固定ホームページに設定します。

# プロジェクト構成とパッケージ作成

テーマのソースはリポジトリ直下の `style.css`、`functions.php`、`index.php`、`template-map.php`、`admin/`、`inc/`、`assets/` にあります。`tests/`、`scripts/`、`promo/` は開発・宣伝用です。

リポジトリ直下で実行します：

```powershell
pwsh -File ./scripts/package-theme.ps1
```

`dist/Sphotography.zip` を生成します。ZIP 内には `Sphotography/` テーマディレクトリが一階層あり、WordPress の「外観 → テーマ → 新しいテーマを追加 → テーマのアップロード」から直接インストールできます。実行用ファイル、スクリーンショット、ライセンスのみを収録し、テスト、ビルドキャッシュ、宣伝素材、古いアーカイブは除外します。管理画面の更新機能は現在の構成と旧版の入れ子構成に対応しています。
